# Income and Savings Linear Regression Model
A Python script that uses simple linear regression to predict monthly savings based on monthly income.

# Files
1. "simple_linear_regression_model.py" - the main Python script.
2. "monthly_income.xlsx" - dataset with 10 records.

# How to Run?
1. Clone this repository.
2. Install the requirements. (see the file attached "requirements.txt")
3. Run: python simple_linear_regression_model.py
